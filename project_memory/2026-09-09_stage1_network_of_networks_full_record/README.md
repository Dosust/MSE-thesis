## Purpose

This folder consolidates the full scientific content developed in the 2026-09-09 thesis conversation concerning:

- what belongs inside the Power, Transportation, Information, and Organizational subsystems;
- what is a node, link, interface asset, port, agent, parameter, or dynamic state;
- how to construct a heterogeneous directed network-of-networks;
- how to audit all interdependencies without inventing unsupported links;
- how to preserve a clean handoff to Stage 2 causal mechanisms, Stage 3 hybrid dynamics, Stage 4 feedback/control, Stage 5 viability, and Stages 6-7 sustainability transformation;
- the scientific references supporting each modeling decision.
