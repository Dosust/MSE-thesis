# Type I, Type II and Type III End-to-End Thesis Frameworks

These three frameworks traverse the complete research chain but place the main original contribution in different locations.

---

# Type I — Theory-First Integrated Mathematical Thesis

## Working title family

**Mathematical Physics and Viability-Control Theory for Sustainable Coupled Infrastructure Systems**

## Governing question

**What is mathematically possible?**

## Architecture

```text
physical principles
→ coupled infrastructure representation
→ dynamic interfaces
→ hybrid/multiscale dynamics
→ sustainable/equitable admissibility
→ viability geometry
→ recovery/capture geometry
→ viability-preserving control
→ resilience-constrained design
→ optimization
→ decision
```

Compact mathematical mapping:

```text
(theta,eta) → X(t) → V_R → C_R → u → d → decision
```

## Main novelty zone

```text
dynamic interfaces
+ viability-boundary geometry
+ sustainability/equity constraints
+ recovery geometry
```

## Strength

Strongest mathematical-physics identity and strongest path toward theorem-level questions.

## Risk

Can become too broad for one MSE if each stage is treated as an independent original contribution. The recommended MSE interpretation is to make the dynamic/viability core original and treat design/decision as downstream demonstrations.

# Type II — Digital Twin / Inference-to-Decision Thesis

## Working title family

**Uncertainty-Aware Digital Twin for Sustainable and Resilient Coupled Infrastructure Systems under Climate Stress**

## Governing question

**What is happening, what will happen, and what should be done now?**

## Architecture

```text
physical infrastructure + sensing
→ observations
→ inverse problems / interface identification
→ state + parameter + uncertainty estimation
→ dynamic digital twin
→ forecasting
→ probabilistic resilience / viability
→ adaptive control
→ adaptive design
→ optimization
→ decision support
```

Compact mapping:

```text
D → p(X,theta,Z|D) → p(V_R) → u_t → adaptive design / decision
```

## Main novelty zone

```text
dynamic-interface identification
+ uncertainty propagation
+ probabilistic viability
+ adaptive control
```

## Strength

Strongest end-to-end engineering-science framework when real observations, state estimation and adaptive decision support are central.

## Risk

A full operational digital twin requires data, sensing, calibration and software infrastructure. For the current MSE, avoid claiming a real-time operational twin unless those elements are actually implemented and validated.

# Type III — Resilience-by-Design Thesis

## Working title family

**Resilience-by-Design Optimization of Sustainable Interdependent Infrastructure Systems under Climate Uncertainty**

## Governing question

**What should be built so that acceptable behavior remains possible?**

## Architecture

```text
performance / service requirements
→ hazard scenarios
→ candidate infrastructure designs
→ design-dependent physical/network model
→ dynamic simulation
→ viability / recovery assessment
→ control feasibility
→ resilience design constraints
→ sustainability/equity constraints
→ multiobjective / robust optimization
→ investment / planning decision
```

Compact mapping:

```text
d → F_d → V_R(d) → C_R(d) → d* → decision
```

## Main novelty zone

```text
viability as a design constraint
+ recoverability constraint
+ sustainability/equity constraint
+ robust multiobjective design
```

## Strength

Strongest sustainable-engineering and infrastructure-design translation of the mathematical framework.

## Risk

If viability/recovery geometry is reduced to one objective score, the thesis can collapse into a conventional optimization study. The distinctive contribution is to preserve resilience as a feasibility/geometry constraint.

# Relationship among the three

The three philosophies can be interpreted as a long-term research program:

```text
Type I: know what is possible
→ Type II: know what is happening
→ Type III: know what to build / choose
```

Equivalent verbs:

```text
UNDERSTAND / PROVE
→ INFER / PREDICT / CONTROL
→ DESIGN / OPTIMIZE / DECIDE
```

## Recommended present MSE position

The current MSE should not attempt equal novelty in all three. The strongest coherent configuration remains a **Type-I-centered architecture with Type-II upstream identification/UQ and a limited Type-III downstream demonstration**.

That is:

```text
observations
→ identify uncertain interfaces
→ coupled dynamic model
→ sustainable/equitable viability and recovery geometry
→ admissible recovery control
→ small design/decision demonstration
```
