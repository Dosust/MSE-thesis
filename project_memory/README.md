## Memory versus evidence

Memory capsules provide **high recall**. They do not replace authoritative evidence. For final scientific claims, follow the links to the original literature/evidence records, code, datasets, prompts, transcript files, hashes and provenance artifacts.

## Authenticity rule

A memory synthesis is not a verbatim transcript. Exact transcript claims belong under `conversation/`; source integrity and binary/archive provenance belong under `provenance/`.
