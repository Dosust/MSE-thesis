## Purpose

This folder preserves the complete scientific refinement of **Stage 1 — Multilayer Structure** developed after the initial network-of-networks formulation. It is designed to be reusable in GitHub, Overleaf, Miro/Canvs, XMind, MindMap AI, draw.io, Python, Julia, MATLAB, and thesis manuscripts.

## Governing principle

```math
\boxed{\text{Network-of-networks is necessary, but not sufficient.}}
```

A network-of-networks captures the structural skeleton: systems, nodes, links, interfaces, and known directed dependencies. The thesis additionally requires explicit representation of non-dependencies, conditional dependencies, hidden/latent candidates, common-cause exposure, uncertainty, and evidence provenance.

The Stage-1 knowledge base is therefore represented as:

```math
\boxed{\mathfrak M_1=(\mathcal G,\mathcal R,\mathcal U,\mathcal H,\mathcal E,Y_0)}
```

and operationalized through the Stage-1A completeness protocol.
