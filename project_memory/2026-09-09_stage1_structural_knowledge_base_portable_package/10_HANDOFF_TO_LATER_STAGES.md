# Handoff from Stage 1 to Later Stages

## Stage 1 endpoint

Stage 1 ends when the structural knowledge base is frozen:

```math
\boxed{\mathfrak M_1^{*}=(\Omega,\mathcal G,\mathcal Q_{adm},\mathbf S,\mathcal R_D,\mathcal R_N,\mathcal R_C,\mathcal R_L,\mathcal R_U,\mathcal E_{prov},Y_0,\Lambda_{sus})}
```

This means:

- entities are defined;
- topology is defined;
- candidate cross-system relations are audited;
- every admissible relation has a status;
- evidence/provenance is stored;
- latent and unresolved relations remain explicit;
- the initial state is simulation-ready.

## Stage 2 — Causal Mechanisms

Stage 2 receives only structurally admissible candidate relations and asks:

```math
\boxed{\text{What causes what, through which mechanism, under what conditions?}}
```

Stage 2 adds event nodes, causal mechanisms, trigger conditions, common-cause classification, and evidence for causal direction.

Stage 1 does **not** infer causality automatically from connectivity.

## Stage 3 — Coupled Hybrid Multiscale Dynamics

Stage 3 receives validated causal pathways and adds:

```math
\boxed{F,\;J,\;\tau,\;Z(t)}
```

for continuous dynamics, discrete jumps, delays, and evolving interface states.

```math
\boxed{\text{Stage 1 edge existence/meaning}\neq\text{Stage 3 edge dynamics}}
```

## Stage 4 — Feedback & Control

Stage 4 introduces observation, state estimation, organizational decision, control policy, and intervention:

```math
\boxed{H_{obs},\hat Y,I,O,\pi,u}
```

## Stage 5 — Viability

Stage 5 determines whether trajectories remain inside the admissible set:

```math
\boxed{K,\mathcal V,R}
```

## Stage 6 — Resilience-to-Sustainability Transformation Interface

Stage 1 stores only sustainability-traceable metadata `\Lambda_{sus}`. Stage 6 combines resilience outputs with this metadata and external sustainability datasets/models:

```math
\boxed{R+\Lambda_{sus}+D_{sus}\xrightarrow{\Phi_{sus}}S_{req}}
```

This translates resilience findings into requirements for energy, carbon, cost, resource use, accessibility, organizational capacity, and investment.

## Stage 7 — Sustainable Transformation Pathways

Stage 7 converts requirements into technical, organizational, environmental, policy, and governance transformation alternatives.

## Canonical sequence

```math
\boxed{
\mathfrak M_1^*
\rightarrow
\mathfrak M_2
\rightarrow
(F,J,\tau,Z(t))
\rightarrow
(H_{obs},\hat Y,I,O,\pi,u)
\rightarrow
(K,\mathcal V,R)
\rightarrow
\Phi_{sus}
\rightarrow
S_{req}
\rightarrow
\text{Transformation Pathways}
}
```

## Boundary rule

Do not move sustainability objectives upstream into Stage 1–5. The resilience framework remains intact; sustainability is connected downstream through Stages 6–7.
