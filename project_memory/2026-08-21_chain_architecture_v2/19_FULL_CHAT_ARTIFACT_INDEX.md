## 12. Files added concurrently by other repository work

The repository may contain other evidence/review work, including material under `evidence/` added by concurrent activity.

Do not automatically import such material into the current chain-architecture thesis state. First ask:

1. Is it scientifically relevant to this thesis question?
2. Is its evidence/provenance compatible?
3. Does it alter any frozen scope/proposition?
4. Does it belong to a different project/review thread?

This prevents repository-wide co-location from becoming false scientific integration.
