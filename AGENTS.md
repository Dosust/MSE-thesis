# Repository Working Instructions

## 1. Chapter I activation rule

Whenever a task refers to **Chapter I**, **Chapter 1**, **Introduction**, the introductory research architecture, or asks to draft/revise/present a Chapter-I section, first load and follow:

`project/CANONICAL_CHAPTER_I_CONTENT_AND_FLOW_V2.md`

Then load:

`project/CANONICAL_RQ_SO_HYPOTHESES_V3.md`

That pair controls Chapter-I flow, exact question/objective wording, and H1–H5 mapping.

### Required Chapter-I behavior

1. Treat the **160-page thesis ceiling** and **16–18-page Chapter-I target** as internal planning constraints, not ASU requirements.
2. Preserve the Chapter-I sequence:

```text
Context → Problem → Gap → Scope → Framework → Questions → Objectives → Hypotheses/developmental tests → Proposed contribution
```

3. Preserve:

```text
structure ≠ causality ≠ dynamics ≠ knowledge/control ≠ resilience ≠ intervention performance ≠ sustainability consequences ≠ decision
```

4. Preserve the active seven-stage scientific dependency:

```text
Spatiotemporal SoS Structure
→ Causal Interdependencies
→ Hybrid Dynamics
→ Observation/Estimation/Organization/Control
→ Viability + Reachability + Probability
→ Diagnosis + Intervention + Effectiveness + Efficiency + Sustainability Consequences
→ Engineering Decision / Transformation
```

5. Preserve `P,T` as the physical infrastructure systems and `I,O` as supporting informational/organizational domains unless a versioned model revision changes that definition.
6. Preserve operational control `u(t)` versus strategic intervention `a_k`.
7. Preserve:

```text
resilience ≠ effectiveness ≠ efficiency ≠ sustainability
```

8. Preserve `RQ1–RQ7 ↔ SO1–SO7`; RQ1/RQ2 have developmental evidence obligations, while RQ3–RQ7 map to H1–H5 respectively.
9. Do not infer novelty from silence. Gap/novelty statements require the declared reproducible evidence audit.
10. Keep detailed mathematical derivation primarily in Chapter III and experiments/VVUQ primarily in Chapter IV.
11. Never silently rewrite canonical Chapter-I or RQ/SO/H authorities. Use a versioned amendment.

## 4. Thesis-wide scientific writing and inference rule

For drafting, rewriting, reviewing or freezing thesis prose, load:

`thesis/00_governance/SCIENTIFIC_WRITING_AND_INFERENCE_STANDARD_V1.md`

and preserve the chain:

```text
Question
→ Objective
→ Scientific object
→ Assumptions
→ Method
→ Comparator/developmental criterion
→ Evidence
→ Uncertainty
→ Result
→ Inference
→ Validity domain
→ Engineering implication
```

Use one primary epistemic state for every material statement:

```text
[E] external evidence
[D] derived
[H] hypothesis
[P] proposal
[A] assumption
[U] unresolved
[R] registered result
```

No claim may be strengthened merely through polished wording.

## 6. Experiment and result control

Before discussing a hypothesis test, load:

`thesis/00_governance/MODEL_EXPERIMENT_VALIDATION_MATRIX.md`

Every confirmatory analysis must expose:

```text
hypothesis + baseline + treatment + held conditions + domain + data role + metric + threshold + uncertainty + V&V + falsification
```

A failed evidence/data/solver/preregistration gate means **NOT TESTED**, not hypothesis falsification.

No preferred model is validated alone.
