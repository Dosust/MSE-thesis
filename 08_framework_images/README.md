## Repository-copy policy

The GitHub copies are optimized WebP versions so the connected GitHub interface can reliably store and render the generated visuals. The original PNG identities are preserved cryptographically above; `imagegen.png` is an exact byte duplicate of the Type I PNG and is therefore represented by an alias to the same Git object.

These images are research-framework visualizations, not empirical results. Their mathematical notation should be checked against the frozen thesis architecture before direct publication in the final dissertation.
