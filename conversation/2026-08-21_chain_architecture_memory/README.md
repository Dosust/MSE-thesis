## Core scientific state

The master ontology is not one giant causal arrow. It is six interacting chains:

- **I. Physical system:** physical laws → structure → interdependencies/interfaces → states/flows → dynamics → cascades.
- **II. Observation/inference:** observe → identify → estimate → quantify uncertainty → predict.
- **III. Hazard/failure/consequence:** hazard → exposure → vulnerability → damage → cascades → function loss → service loss → consequences → risk.
- **IV. Resilience/viability/recovery:** state → viability → reachability → resilience/service continuity → recoverability → recovery → adaptive control.
- **V. Engineering lifecycle:** requirements → design → deploy → operate → monitor → maintain → retrofit/expand → adapt → circularize.
- **VI. Sustainability/equity/governance/decision:** needs → alternatives → evaluate → trade-offs → decide → implement → learn → revise.

Across all six chains run mathematical engines: network science, ODE/PDE/dynamical systems, probability/stochastic processes, inverse problems, Bayesian inference, UQ, numerical analysis, viability/reachability, control, optimization, machine learning/physics-informed AI, and decision/game theory.

## Current thesis center of gravity

The current thesis should not claim equal novelty in all six chains. Its strongest mathematical center is:

`Chain I (physical/coupled dynamics) + Chain IV (viability/reachability/recovery)`

with strong support from:

`Chain II (inverse problems/identification/UQ)`

and Chain III providing disturbance/failure mechanisms while Chains V–VI provide downstream engineering and decision applications.

A concise research objective is:

> Establish conditions under which a dynamically coupled power–water–transportation–solid-waste infrastructure system is well posed, identifiable, stable, sustainably/equitably viable, recoverable, and controllable under climate-driven disturbance and uncertainty.

## Important novelty boundary

Do **not** claim novelty for viability theory, HJ reachability, multilayer networks, percolation, inverse problems, PINNs, Sobol sensitivity, resilience curves, restoration optimization, or stochastic multi-objective optimization by themselves. The prospective contribution is their rigorous integration around **dynamic infrastructure interface mechanisms**, **service-state mapping**, and **sustainability/equity-constrained viability/recoverability**.
