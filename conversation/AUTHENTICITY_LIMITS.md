# Authenticity Limits

This archive preserves **all thesis artifacts currently accessible in the active session** and the exact user request text available to that session.

It does **not** claim to contain a complete export of every historical ChatGPT conversation in the project, because the full verbatim transcript of all older chats is not available through the active tools.

Therefore:

- current-thread requests are preserved verbatim;
- older exact request fragments are labeled as fragments;
- pasted/generated reference material is stored separately from authentic user requests;
- no missing historical wording is reconstructed or invented.

## Assistant-response boundary

The active interface does not expose a canonical raw-conversation export API to the assistant. Therefore, exact user requests preserved in the current-thread request file are the strongest verbatim source. Assistant final responses are preserved from visible conversation context where available. Long responses that already exist as source files are cross-referenced rather than silently reconstructed. Hidden reasoning, system/developer instructions, and tool-internal payloads are never represented as user-visible conversation text.
