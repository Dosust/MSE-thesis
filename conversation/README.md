# Conversation provenance

This directory preserves the thesis-development conversation material that is available in the active ChatGPT session.

## Files

- `user_requests_verbatim_2026-08-20.md` — verbatim user requests available from the current thread.
- `assistant_final_responses_2026-08-20.md` — visible assistant final-response text preserved from the current thread.
- `project_history_preserved_request_fragments.md` — exact older request fragments retained in project context.
- `AUTHENTICITY_LIMITS.md` — boundaries of what can be called a verbatim transcript.

## Important boundary

This is a provenance archive, not a claim that hidden model reasoning, tool payloads, system messages, or every transient UI progress line are part of the user's conversation record. Those are deliberately excluded. No hidden chain-of-thought is archived.
