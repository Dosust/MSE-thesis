# Visual Design and Fidelity Decisions

## Design objective

Create a thesis-grade, professional, high-resolution visual representation of the canonical seven-stage framework without changing the scientific content.

## Production stack selected in the conversation

- **MindMap AI** - scientific ontology and hierarchy.
- **Mermaid / Graphviz** - logical validation and reproducible graph structure.
- **LaTeX / TikZ** - publication-grade mathematical figure source.
- **FigJam** - systems architecture and causal-flow layout.
- **Figma** - master deterministic vector design.
- **Canva** - presentation/animation derivative.
- **Python** - computational/structural validation.
- **GitHub** - durable source of truth and version control.

## Preferred visual architecture

The conversation moved away from a simple sequence of seven equal boxes. The preferred scientific hierarchy is:

```text
Multilayer physical architecture
        ->
Core resilience analytical engine
  [causality -> hybrid dynamics -> feedback/control -> viability]
        ->
Narrow transformation interface
        ->
Branching sustainable transformation pathways
```

A tree/mind-map composition was then selected as a strong visual grammar because it allows:

- one central organizing spine;
- alternating stage cards;
- clear visual progression;
- blue resilience-analysis region;
- blue-to-green Stage 6 transition;
- green sustainable-transformation region.

## Thesis-facing visual specification

- White background.
- Times New Roman for thesis-facing text when possible.
- Restrained navy/blue for Stages 1-5.
- Stage 6 as a narrow transition/interface, visually distinct from ordinary stages.
- Restrained green for Stage 7.
- Standardized icon size and stroke style.
- Consistent card radius, margins, spacing and border weights.
- Minimal shadows.
- No decorative visual element may carry new scientific meaning.
- Final master should be vector (SVG/PDF) from Figma/TikZ/SVG workflows.
- High-resolution raster derivatives may be exported for presentations/print.

## Image-generation audit

Several generated framework images were reviewed. They were considered useful as visual drafts, but not automatically authoritative because generative rendering introduced or paraphrased content.

### Examples of non-canonical additions identified

- SDG panels or logos.
- "Downstream Thesis Outputs and Applications" sections.
- Extra application examples.
- Extra pathway variables such as `S_T,S_O,S_E,S_P` when not frozen.
- Added labels such as critical interfaces, recovery bottlenecks, trade-offs, synergies or co-benefits.
- Explanatory subtitles under the mathematical hierarchy that changed or expanded the intended meaning.
- Geometry-heavy notation not included in the current canonical framework.

## Required corrections for the current tree-style image

1. **Title** - use the thesis title: **Causal-Hybrid Multilayer Resilience-to-Sustainability Framework for Interdependent Power-Transportation Systems**.
2. **Stage 1 role** - use exactly **P-T-I-O architecture**; do not add `(power, transport, ICT, others)` or similar expansions.
3. **Stage 5 viability graphic** - retain only canonical viability content `K` and `V` unless a new symbol is explicitly approved.
4. **Stage 6** - visually encode only the authorized translation logic `R -> T_ST -> S` plus the exact role/question.
5. **Stage 7** - technical, organizational, environmental and policy transformation may be shown because those categories are canonical.
6. **Footer** - use only the canonical mathematical hierarchy.
7. **Domain separation** - make Stages 1-5 visibly the resilience-analysis domain, Stage 6 the translation interface, and Stage 7 the sustainability-transformation domain.

## Deterministic final-figure rule

Generative images can be used for layout exploration. A thesis-final figure should be rebuilt in Figma, TikZ/LaTeX, SVG or another deterministic vector workflow and audited word-for-word against the canonical specification.

## Governing rule

```math
\boxed{\textbf{CHANGE THE VISUAL HIERARCHY, NOT THE SCIENTIFIC CONTENT.}}
```
