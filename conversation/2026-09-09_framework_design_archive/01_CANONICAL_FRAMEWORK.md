# Canonical Seven-Stage Framework

## Thesis title

**Causal-Hybrid Multilayer Resilience-to-Sustainability Framework for Interdependent Power-Transportation Systems**

## Canonical sequence

```math
\boxed{
\text{Multilayer Structure}
\rightarrow
\text{Causal Mechanisms}
\rightarrow
\text{Coupled Hybrid Multiscale Dynamics}
\rightarrow
\text{Feedback \& Control}
\rightarrow
\text{Viability}
\rightarrow
\text{Resilience-to-Sustainability Transformation Interface}
\rightarrow
\text{Sustainable Transformation Pathways}
}
```

| Stage | Role | Main question |

## Mind-map detail

### 1. Multilayer Structure - What exists?
- Role: P-T-I-O architecture
- Core objects: \(\mathcal G,Y,Z\)
- Power, Transportation, Information, Organization layers
- Directed interdependencies and interfaces

### 2. Causal Mechanisms - Why does disruption propagate?
- Role: Cross-layer cause-effect pathways
- Core objects: \(\mathcal C,e_i\rightarrow e_j,z_{ij}\)
- Hazards and disruptive events
- Mechanism, direction, interface, propagation pathway

### 3. Coupled Hybrid Multiscale Dynamics - How and when does it evolve?
- Role: Coupling + continuous dynamics + discrete events + timescales
- Core objects: \(Z,F,J,\tau\)
- Between events: \(\dot Y=F(Y,u,h;\tau)\)
- At events: \(Y^+=J_e(Y^-,e)\)
- Coupling strengths, propagation delays, cascade and recovery trajectories

### 4. Feedback & Control - How does the system respond?
- Role: Information, organization, decisions, intervention
- Core objects: \(\mathcal H_{\rm obs},\hat Y,I,O,\pi,u\)
- Observation and state estimation
- \(u(t)=\pi(\hat Y(t),I(t),O(t))\)
- Repair, routing, resource allocation, coordination

### 5. Viability - Can it survive?
- Role: Survival/recoverability under constraints
- Core objects: \(K,\mathcal V\)
- Determine viable and non-viable system states
- Evaluate whether coordinated control preserves acceptable operation

### 6. Resilience-to-Sustainability Transformation Interface - What do the resilience results imply for sustainability?
- Role: Translate resilience findings into transformation requirements
- Resilience outputs \(R\)
- Transformation operator: \(R\rightarrow\mathcal T_{ST}\rightarrow S\)
- Convert dependencies, cascades, delays, recovery and viability findings into sustainability decision inputs

### 7. Sustainable Transformation Pathways - What should be changed for long-term sustainability?
- Role: Technical, organizational, environmental and policy transformation
- Technical transformation pathways
- Organizational and governance pathways
- Environmental and resource-efficiency pathways
- Long-term sustainability decisions informed by resilience evidence
