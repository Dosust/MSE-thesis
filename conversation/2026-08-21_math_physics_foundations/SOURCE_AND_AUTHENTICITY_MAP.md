## 2. Authenticity rule for conversation memory

This capsule is a **high-rigor synthesis**, not a guaranteed byte-for-byte transcript of every message ever exchanged.

Reason:

- the repository already contains earlier verbatim/reconstructed conversation archives;
- the active chat runtime may expose some earlier content through summaries rather than literal full message bodies;
- therefore only text known to be exact should be labeled “verbatim.”

Future chats should distinguish:

1. `verbatim` — exact text preserved from a known source;
2. `source-derived` — faithful summary of supplied source material;
3. `reconstructed` — reconstructed from available conversation state;
4. `synthesis` — new structured synthesis created for continuity;
5. `hypothesis` — research proposition requiring testing.

Do not silently relabel reconstructed/synthesized content as verbatim user text.

## 3. Suggested evidence-level field

For future machine-readable provenance, use a status field such as:

- `S0`: official standard/taxonomy,
- `S1`: formal ontology/semantic relation,
- `S2`: theorem/formal mathematical dependency,
- `S3`: peer-reviewed literature-supported relation,
- `S4`: project hypothesis/proposed relation.

This hierarchy was discussed as a useful architecture for a provenance-aware mathematical knowledge graph. It is a project evidence convention unless formally mapped to an external standard.

## 4. Literature citation discipline

Every future literature-derived claim should preserve at least:

- title,
- authors,
- year,
- DOI/URL where available,
- what exact claim it supports,
- whether it supports a general theory, an application, a method, or a gap.

## 5. Reproducibility discipline

A future result should be reproducible from:

\[
\boxed{\text{source data}+\text{model specification}+\text{code}+\text{parameters}+\text{seed}+\text{software version}+\text{commit SHA}}.
\]

For figures, preserve editable/vector source where possible.

For numerical experiments, preserve machine-readable outputs plus a human-readable interpretation.

For thesis claims, preserve both supporting and falsifying evidence.
