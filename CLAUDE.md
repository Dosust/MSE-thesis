# Claude Repository Instructions

For all active thesis work, first read:

- `AI_RESEARCH_INSTRUCTIONS.md`
- `project/CURRENT_THESIS_AUTHORITY_INDEX_V1.md`
- `project/CANONICAL_EVIDENCE_NON_INVENTION_STANDARD_V1.md`

The evidence/non-invention authority is mandatory.

```text
No invention fills an evidence gap.
Unverified scientific content remains OPEN.
Thesis-derived objects must be labeled T1 / thesis-derived.
Transferred values or laws require explicit transferability justification.
```

Do not invent papers, DOI metadata, standards or clauses, equations, thresholds, parameters, material properties, equipment limits, validation claims, uncertainty bounds, or numerical results. Use the active repository authorities rather than historical files when conflicts exist.
