## 5. How EACH data stream must be handled
1. Identity: DOI/source/creator/asset/site, publisher original filename, version, permission/license; protect source.
2. Integrity: hash bytes, count rows/cols, duplicate/missingness, original vs derived/calculated separation. Hashes from a prior report are **reported**, not freshly rechecked.
3. Semantics: units, electrical meter boundary (P,Q,U,I; AC vs DC), sensor location, whether reported T is transformer HST vs vehicle battery/coolant vs EVSE junction, rated equipment and phase activity.
4. Time/context: original timezone, sampling cadence and gaps, actual chronological comparisons, whether stations share electrical **topology** and clocks. No merging disjoint sites to create synthetic 'measured' coupling.
5. Modeling role: measured component calibration vs external holdout vs controlled-lab response vs network scenario input vs software demo/quarantine.
6. Scientific evaluation: physics conservation, parameter identifiability, train/test temporal separation, uncertainty and hot-extreme OOD caveats; PINN/FVM only **comparators** on fair identical measured inputs.
7. Claim language: measured electrical response ≠ verified physical control mechanism; HST-derived ageing ≠ true observed years lost; charging kWh ≠ observed missed trips; cost ≠ emissions; resilience requires state→capability→service through disturbance/recovery.
