This directory is the active mathematical/scientific specification of the MSE thesis. The seven-stage framework and five-primary-hypothesis logic are frozen. The active evidence methodology is now **FTEE v2.0**, which begins from a fresh reproducible search built from the current hypotheses and scientific mechanisms. Prior memory, earlier rankings, and historical corpora do not determine inclusion.

> **Canonical reasoning protocol:** [`RESEARCH_REASONING_PROTOCOL.md`](RESEARCH_REASONING_PROTOCOL.md) governs how every claim, method, equation, simulation, hypothesis, figure, and engineering recommendation is learned, verified, formalized, tested, validated, synthesized, and advanced.

> **Governing evidence rule:** a paper becomes primary thesis evidence only because the new reproducible search finds it and the new eligibility protocol qualifies it.

## 4. Active evidence architecture — FTEE v2.0

The complete current evidence path is

```math
\begin{aligned}
H_i
&\rightarrow \text{mechanism concepts}
\rightarrow \text{fresh database search}
\rightarrow \text{screening}\\
&\rightarrow P_i
\rightarrow e_{ij}
\rightarrow M_{ij}
\rightarrow F_{ij}\\
&\rightarrow (X,\theta,A,\Omega)
\rightarrow (V,U)
\rightarrow \mathfrak M_{\rm required}\\
&\rightarrow \text{candidate demonstrators}
\rightarrow \text{V\&V/UQ/identifiability gates}
\rightarrow \mathcal M_D^\star.
\end{aligned}
```

Previously known and unknown papers are equivalent with respect to discovery, screening and qualification:

```math
P_{\rm known}\equiv P_{\rm unknown}.
```

The fresh eligible corpus is

```math
\mathcal P_{\rm eligible}^{\rm NEW},
```

and is the sole primary input to full-text FTEE extraction.

## 5. Search and screening rules

The five hypotheses define separate search families:

```math
\mathcal S=\{S_{H_1},S_{H_2},S_{H_3},S_{H_4},S_{H_5}\}.
```

The default primary databases are Scopus, Web of Science, Compendex and IEEE Xplore, supplemented where scientifically justified. The default time window is database inception to final search date unless a narrower interval is justified beforehand.

The discovery set is

```math
\mathcal P_{\rm discovered}
=
\mathcal P_{\rm database}
\cup
\mathcal P_{\rm backward}
\cup
\mathcal P_{\rm forward}.
```

Database search comes first; citation chasing begins from newly eligible anchors, not remembered papers. Search queries are versioned and never overwritten.

Eligibility and exclusion criteria must be frozen before screening. PRISMA-style accounting tracks identification, deduplication, title/abstract screening, full-text eligibility, and final eligibility, with coded full-text exclusion reasons.

## 6. FTEE evidence-unit logic

The extraction unit is

```math
e_{ij}
=
(S_i,L_{ij},C_{ij},M_{ij},F_{ij},X_{ij},\theta_{ij},A_{ij},\Omega_{ij},V_{ij},U_{ij},H_{ij}).
```

FTEE v2.0 preserves source notation before thesis mapping, separates mechanism evidence $E_M$, mathematical-form evidence $E_F$ and validation evidence $E_V$, audits dimensions and parameters, distinguishes calibration from validation, tracks validation domain $\Omega_V$, records uncertainty, extracts rival/contrary evidence, and prohibits silent equation completion.

The early acceptance gate is

```math
Q_E
=
Q_{\rm provenance}
\land Q_{\rm mechanism}
\land Q_{\rm interpretation}
\land Q_{\rm domain}
\land Q_{\rm relevance},
```

while governing-equation qualification additionally requires variables, assumptions, parameters, mathematical consistency and credibility.

The old corpus is secondary only:


is a post hoc coverage audit after the fresh corpus is constructed. An old-only paper is never automatically added. If it exposes a search weakness, repair and rerun the search systematically.
