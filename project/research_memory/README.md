## Archive rule

Historical files are preserved to document how the research evolved. Do not silently edit their scientific content to make them look current. If a historical concept is reintroduced into the thesis, it must pass through an explicit, versioned change to the current canonical files.

| Location | Meaning |

| `project/research_memory/**` | Historical research state / provenance |
| `provenance/**` | Audit trail and change records |

The gray badge and this README are deliberate: **archive status is both textually and visually encoded**, so meaning is retained even without color.
