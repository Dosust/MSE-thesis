Treat this repository folder as the canonical research-memory snapshot for the six-chain mathematical-physics review. Preserve provenance distinctions. Do not claim that the literature proposes one pre-existing six-chain framework.

### Frozen architecture
1. Physical system: laws → components → topology → interfaces → states/flows → dynamics → cascades.
2. Observation/inference: measurement → observability → identification → calibration → estimation → assimilation → UQ → prediction.
3. Stress/consequence: hazard → exposure → vulnerability → fragility → damage → cascade → functionality → service → consequences → risk.
4. Viability/response: preparedness → absorption/robustness → viability → reachability → continuity → recovery/restoration → allocation → adaptive control.
5. Engineering lifecycle: requirements → design → deploy/commission → operate/monitor → age → maintain/repair/replace → plan/retrofit → adapt/transform → decommission/circularize.
6. Societal decision: evaluate sustainability/equity/economics/governance → trade off → decide → implement → observe outcomes → learn/update.

### Frozen distinctions
- topology ≠ interdependency ≠ interface mechanism
- damage ≠ functionality ≠ service ≠ consequence
- resilience ≠ sustainability
- recovery is explicit
- optimization is cross-cutting
- societal choice is normative/institutional, not a downstream physical state
- six chains interact through feedback rather than one giant arrow
