# SIX INTERACTING SCIENTIFIC CHAINS — CANONICAL V2 ONTOLOGY

## I. Physical System — What is the system?
**Physical laws → Components → Topology → Interfaces/interdependencies → States & flows → Dynamics → Cascades**

Layers include governing/constitutive laws; asset states; graph/multilayer topology; mechanism-specific interfaces; stocks/flows/capacities; ODE/PDE/DAE/hybrid/stochastic dynamics; cascading propagation.

## II. Observation & Inference — What do we know?
**Measurement → Observability → Identification → Calibration → State estimation → Data assimilation → Uncertainty quantification → Prediction**

Layers include sensing/data quality; identifiability; inverse problems/Bayesian inference; model updating; filtering; assimilation; parameter/state/structural UQ; predictive distributions.

## III. Stress & Consequence — What happens under stress?
**Hazard → Exposure → Vulnerability → Fragility → Damage/failure → Interdependent cascade → Functional loss → Service loss → Human/socio-technical response → Societal consequence → Risk/criticality**

Critical mapping:
`X(t) → F(t) → S(t) → C(t)`
where physical state, functionality, delivered service, and societal consequence are distinct.

## IV. Viability & Response — Can the system survive and recover?
**Preparedness/absorption/robustness → Viability → Reachability → Critical-service continuity → Resilience metrics → Recoverability → Restoration → Resource allocation → Adaptive/feedback control → Recovered/adapted/transformed state**

Viability/reachability answer safe/admissible-state questions; resilience metrics summarize loss/recovery; restoration has its own dynamics and resource constraints.

## V. Engineering Lifecycle — What can engineers do?
**Requirements → Design → Deployment → Commissioning → Operation/dispatch → Monitoring → Deterioration/aging → Maintenance → Repair/replacement → Retrofit/expansion → Planning/investment timing → Adaptation → Transformation → Decommissioning/circularity**

Optimization is cross-cutting across design, operation, recovery, control, maintenance, planning and adaptation; it is not a lifecycle stage.

## VI. Societal Evaluation–Decision–Learning — What should society choose?
**Evaluate → Trade off → Decide → Implement → Observe outcomes → Learn/update → Re-evaluate**

Evaluation includes sustainability, equity/accessibility/justice, economics/finance, governance, human behaviour and risk. These are normative/institutional/behavioral dimensions, not downstream physical states.

## Cross-chain feedback
- I ↔ II: system state/model ↔ evidence
- II ↔ III: forecast/UQ ↔ stress/failure characterization
- III ↔ IV: loss/consequence ↔ viability/recovery
- IV ↔ V: control/restoration ↔ engineering operation/maintenance/planning
- V ↔ VI: engineering options ↔ values/equity/finance/governance/decisions
- VI → I: implementation/adaptation modifies topology, assets, parameters and interface laws
- VI → II: learning updates priors, models, measurement priorities and uncertainty

## Cross-cutting mathematical engines
ODE/PDE/DAE; dynamical systems; network/multilayer science; probability/statistics; Bayesian inference; inverse problems; UQ; reliability/risk; optimization/operations research; optimal/robust/stochastic control; viability/reachability/HJ/HJI methods; numerical analysis; game theory; MCDA/DMDU; AI/ML/digital twins.
