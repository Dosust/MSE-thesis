# Reality-to-Stage-1→7 Handoff V1

## Stage 1 — structure

Input reality:
```math
(RW01,RW02,RW03)
```

Required handoff:
- entity/location identity;
- CRS/spatial support;
- infrastructure/source classification;
- candidate interface crosswalk.

No causal claim is authorized.

## Stage 2 — mechanism qualification

Input reality:
```math
(RW03,RW06,RW07,RW08)
```

Required handoff:
- directional mechanism evidence;
- activation condition;
- physical/operational pathway;
- parameter evidence state;
- falsification alternatives.

```math
\text{proximity}\neq\text{dependency}
```

## Stage 3 — dynamics

Input reality:
```math
(RW04,RW05,RW06,RW09,RW10,RW11)
```

Required handoff:
- initial/boundary conditions;
- parameter distributions;
- hazard forcing;
- calibration observations;
- independent/reference validation evidence.

## Stage 4 — observation, information, organization, control

Input reality:
```math
(RW12,RW13,RW14)
```

Required handoff:
- measurement map and timing;
- missingness/error semantics;
- information availability;
- roles/authority/resources;
- feasible-control evidence or explicitly bounded scenarios.

No assumed organizational delay may be called empirical.

## Stage 5 — viability/reachability

Input reality:
```math
(RW10,RW11,RW15)
```

Required handoff:
- service threshold authority;
- recovery target/horizon;
- event/recovery validation;
- uncertainty representation.

```math
\text{threshold without evidence}
\Rightarrow
\text{scenario-only or BLOCKED}.
```

## Stage 6 — intervention consequences

Input reality:
```math
(RW16,RW17,RW18)
```

Required handoff:
- opportunity/population data;
- intervention bill-of-quantities/lifetime/cost;
- environmental/economic factors;
- accounting boundary and functional-service basis.

## Stage 7 — decision

Consumes only Stage-6 admissible consequences plus:
- regulatory/institutional feasibility;
- implementation authority;
- budgets/resources;
- uncertainty/robustness;
- explicit value judgment/decision rule.
