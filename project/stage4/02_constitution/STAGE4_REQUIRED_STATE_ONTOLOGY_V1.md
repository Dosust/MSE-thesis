# Stage 4 Required-State Ontology v1

Stage 4 does not estimate every simulator output.

\`\`\`math
\boxed{Y_4^{req}=\{Y_i\in Y^{phys}:H2_i\lor S5_i\lor C_i\}.}
\`\`\`

A candidate is excluded from the latent-state set if it is only a parameter, exogenous input, derived QOI, or unqualified software-fixture state.

For every member of \(Y_4^{req}\), record symbol, physical meaning, units, entity/location, Stage-3 equation, Stage-2 mechanism if applicable, temporal semantics, role in H2/control/Stage 5, and case-binding status.

The canonical ontology is independent of what a particular dataset happens to contain. A missing measurement blocks a case gate; it does not erase the scientific requirement.
