# Stage 4 Organization Specification v1

\`\`\`math
\boxed{\mathfrak O=(V_O,E_O,A_O,R_O,\tau_O,\Xi_O)}
\`\`\`

- \(V_O\): actors/organizations;
- \(E_O\): coordination relationships;
- \(A_O\): authority/permission structure;
- \(R_O\): resource ownership/availability;
- \(\tau_O\): decision/approval/coordination delays;
- \(\Xi_O\): rules/procedures.

Its dynamic state is \(z_O(t)\), therefore

\`\`\`math
\boxed{\mathfrak O\neq z_O(t).}
\`\`\`

The canonical rule is **information available ≠ authority to act**. Every numerical organizational parameter carries a source status (\`EMPIRICAL\`, \`DATASET_DERIVED\`, \`LITERATURE_BOUNDED\`, \`SCENARIO\`, or \`OPEN\`); undocumented defaults are prohibited.
