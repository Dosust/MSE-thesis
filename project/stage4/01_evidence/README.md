## Scientific use

Each retained source must be interpreted through the thesis evidence taxonomy:

`[E]` established, `[D]` derived, `[H]` hypothesis, `[P]` proposal, `[A]` assumption, `[U]` unresolved.

The literature base supports the **components** of Stage 4. The integrated chain

`Y_phys -> y -> I_t -> b_t -> z_O -> U_feas -> u`

is the Stage-4 thesis synthesis and must be tested rather than treated as an established result.

## Claim boundary

The literature base does **not** establish that the current Greensboro/GreenEVT/SMART-DS case has passed observation, estimation, organization/control, H2, or Stage-4-to-5 gates. Those are case-realization and validation questions handled under `03_cases/` and `04_handoff/`.
