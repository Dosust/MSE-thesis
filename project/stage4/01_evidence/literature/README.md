# Stage 4 Literature Evidence

This directory preserves the evidence base used to constitute Stage 4.

## Evidence set

- 68 screened sources in the Stage-4 evidence matrix.
- Evidence-grounded synthesis covering observation, observability, power and transportation state estimation, information constraints, organizational coordination, feasible control, P–T integration, and the Stage-4→5 handoff.
- DOI-linked bibliography, citation index, and citation audit.

The complete 68-row evidence matrix is also embedded in sheet `15_Literature_Evidence` of:

`project/stage4/02_constitution/STAGE4_MASTER_SCIENTIFIC_REGISTER_V1.xlsx`.

Compressed source artifacts are stored here to preserve the reviewed evidence without changing the canonical Stage-4 constitution.

## Scientific boundary

The literature supports the constituent concepts at different maturity levels. Their integration into

`Y_phys → y → I_t → b_t → O → U_feas → u`

is treated as the Stage-4 thesis synthesis to test, not automatically as a novelty claim.

Candidate gaps remain subject to a separate systematic novelty audit.
