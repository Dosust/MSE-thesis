# Stage 4 Status Taxonomy v1

Four independent status axes are mandatory.

| Axis | Values | Meaning |
|---|---|---|
| Epistemic | \`E,D,H,P,A,U\` | established, derived, hypothesis, proposal, assumption, unresolved |
| Data realization | \`DIRECT, DERIVED, PROXY, SYNTHETIC, PSEUDO, MISSING\` | how the case realizes the canonical object |
| Gate | \`PASS, OPEN, BLOCKED, FAIL\` | admissibility status |
| Validation | \`UNVERIFIED, VERIFIED, VALIDATED\` | verification/validation status |

These axes must never be collapsed.
