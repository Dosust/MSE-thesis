Original candidate:

```math

```

```math

```

```math

```

and an application-specific influence measure can derive `w_e` from the causal operator.


### Conditional fields

```text

H  = required only for genuine memory/non-Markovian behavior;
delta = necessary information for delayed relations but can be a mechanism parameter;
c = necessary context/guard information but can be embedded in formal mechanism semantics.
```

### Raw-tuple limitation

The field `m` does not by itself guarantee an executable mathematical coupling operator, and the tuple does not contain the global service functional.

Thus Candidate A is sufficient on D1–D4 only when supplemented by fixed realization and service maps, and it is not minimum as declared.
