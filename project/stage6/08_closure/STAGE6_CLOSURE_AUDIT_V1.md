## 4. Execution completion test

Stage 6 becomes scientifically/empirically closed only when:

1. Stage-5 handoff is qualified;
2. final intervention set is frozen;
3. baseline/functional unit/boundaries are frozen;
4. B6,0–B6,2 verification passes;
5. B6,3 final case is executed;
6. social/environmental/economic VVUQ passes;
7. H4 is adjudicated as SUPPORTED / NOT SUPPORTED / NOT TESTED according to the frozen rules;
8. Stage-7 handoff is frozen with uncertainty and provenance.

A negative or null H4 result does not prevent scientific closure if the valid experiment was executed.

## 5. Claim ceiling before execution

Allowed:

“The Stage-6 methodology, scope, baseline, benchmark, accounting, VVUQ and H4 protocol are frozen.”

Not allowed:

“Intervention X is sustainable.”

“Resilience improvement reduces carbon.”

“Intervention X is equitable.”

“Intervention X should be chosen.”

Those require execution and/or Stage 7.
