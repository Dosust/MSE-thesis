## 10. Chapter 4 — Research Methodology and Experimental Design

### Common EGMIV test object

For each primary hypothesis:

```math
\boxed{
H_i
\rightarrow
D_i
\rightarrow
M_i
\rightarrow
B_i
\rightarrow
E_i
\rightarrow
\Phi_i
\rightarrow
\epsilon_i
\rightarrow
\text{falsification rule}
\rightarrow
\text{validation rule}.
}
```

where:

```text
D_i = data/evidence;
M_i = tested model;
B_i = competing baseline;
E_i = experiment/scenario design;
Phi_i = decision metric;
epsilon_i = prespecified meaningful-effect threshold.
```

### H1

```math
M_0=\text{independent},\qquad
M_1=\text{static coupling},\qquad
M_2=\text{dynamic causal coupling}.
```

Current location: H1 model verification/preregistration complete; raw empirical row-level qualification remains blocked.

### H2

```math
\mathscr N_0=P+T,
\qquad
\mathscr N_1=P+T+I,
\qquad
\mathscr N_2=P+T+I+O.
```

Information affects knowledge through `b_t(Y)`; organization affects feasible action through `\mathcal U(z_I,z_O)`.

### H3

Test whether controlled-viability diagnostics add predictive/decision value beyond conventional service-loss/recovery metrics.

### H4

Compare viability-sensitive interface targeting against degree, betweenness, flow/load and other prespecified simpler rankings under matched intervention budgets.

### H5

Compare adaptive trigger-based strategic transformation against prespecified fixed pathways under deep uncertainty while keeping operational recovery and structural transformation distinct.
