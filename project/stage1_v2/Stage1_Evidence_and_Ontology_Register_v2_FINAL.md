# Stage 1 Evidence and Ontology Register v2 — Final Normalized Authority

**Status:** PASS — READY FOR FRAMEWORK FREEZE  
**Scope:** Generic Stage-1 framework for coupled Power–Transportation infrastructure; case instantiations remain separate.  
**Supersedes:** `Stage1_Evidence_and_Ontology_Register_v1`.

## 1. Scientific boundary

Stage 1 establishes **entities, typed layers, structural topology, spatial–temporal context, interfaces, candidate relations, evidence/provenance, service/requirement traceability, and normative context**. It does **not** accept case-specific causal dependency, estimate coupling strength, or define Stage-3 dynamics.

```math
\boxed{\text{Stage 1 = structural possibility}\qquad\text{Stage 2 = causal qualification}}
```

## 2. Frozen notation

```math
\boxed{r_i=\text{spatial geometry/location}}
```
Dynamic states retain $X_P(t),\,X_T(t),\,z_I(t),\,z_O(t),\,Y(t)$.

```math
\boxed{\Gamma_e^{\rm str}=\text{structural-admissibility predicate},\qquad \gamma_e=\text{interface semantics}}
```

```math
\boxed{I_e^{\rm struct}\neq w_e\neq q_e^{\rm evid}}
```
where $I_e^{\mathrm{struct}}$ is Stage-1 structural existence, $w_e$ is coupling strength deferred beyond Stage 1, and $q_e^{\mathrm{evid}}$ is evidence confidence.

## 3. Core Stage-1 relation architecture

```math
\boxed{\mathfrak r_e^{(1)}=(\mathcal V_e,\sigma_e,\Gamma_e^{\rm str},\gamma_e,\Phi_e,d_e,m_e^{\rm cand},c_e^{\rm cand},s_e,\mathcal E_e)}
```

Secondary metadata:

```math
\boxed{a_e=(h_e,\pi_e,\kappa_e,\ell_e,b_e,q_e^{\rm evid},\chi_e^{\rm norm})}
```

Stage-1 structural existence is restricted to:

```math
\boxed{I_e^{\rm struct}\in\{\mathrm{TEMPLATE\_ONLY},\mathrm{CANDIDATE},\mathrm{VERIFIED\_STRUCTURAL},\mathrm{UNRESOLVED},\mathrm{EXCLUDED}\}}
```

and:

```math
\boxed{w_e=\mathrm{NOT\_ESTIMATED\_STAGE1}}
```

## 4. Permanent guardrails

```math
\boxed{\begin{aligned}
\text{topology}&\neq\text{function},\\
\text{proximity}&\neq\text{dependency},\\
\text{correlation}&\neq\text{causality},\\
\text{standardized interface}&\neq\text{case connection},\\
\text{case connection}&\neq\text{causal mechanism},\\
\text{common cause}&\neq\text{cross-infrastructure dependency},\\
\text{existence}&\neq\text{strength}\neq\text{confidence}.
\end{aligned}}
```
