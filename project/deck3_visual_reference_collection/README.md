## Source and rights methodology
The 13 linked sources are verified or user-supplied scientific **starting points**, including the IEEE PES feeder resources, NREL imagery listings, DOE engineering resources, one Wikimedia Commons item, and five journal article DOI entries. Each individual asset and its source/license must be rechecked before reuse. **Every row is NOT_CLEARED and NOT individually visual-inspected.** Avoid redistributing copyrighted source diagrams; reconstruct new original layouts from scientifically justified mechanisms where permissions are not established.

## Asset admission
1. Locate a specific image/figure and record permanent asset URL, author, license, attribution, and actual evidence inspected.
2. Verify electrical topology, interfaces, conservation, component function and candidate thermal causality independently of imagery.
3. Record a single scientific takeaway, physical/system boundaries and arrow quantities/directions/units.
4. Build exact Deck3 13-color sRGB authored palette, all-white canvas and panel interiors; authentic equipment pixels can keep natural colors.
5. Use editable native PowerPoint arrows, controls, labels, math, in-text citations and on-click reveals; never invent numerical curves/results.
6. Reject collisions/illegible elements. Source preservation, animation timing, actual playback and physical validation have separate QA statuses.
