## Nonnegotiable selection and rejection gates
1. Physics, signs, interfaces and actual device topology: HARD GATE. Reject physically misleading arrows regardless of aesthetic score.
2. Distinguish established conservation/device behavior, working hypothesis, independent common external forcing and methodological sequence; label every arrow type.
3. The 40-entry inventory documents scope only. Active model uses only necessary qualified states and equipment.
4. No invented benchmark results, confirmed novelty, empirical cause or verification checkmarks. Always preserve NOT_RUN and OPEN where true.
5. No source-license clearance presumed from sample catalogs; all reused published images are prohibited until item-level proof. Unlabeled original equipment illustration allowed if physically reviewed; native scientific layers preferred.
6. 16:9 ASU widescreen, Times New Roman in native PPT, #FFFFFF all authored surfaces, exact registered 13-color sRGB for marks, no decorative fills/shadow or gradients. Ordinary projected body type target ≥24pt with documented exceptions.
7. Inspect final 1920×1080 render and test native PowerPoint reveal order separately from XML timing checks. No image-generation prompt can certify fonts, claim support or animation.

## Source decision logic
A) Hard reject any concept or presentation variant as *final scientific framework* if it creates false causal claims, hard-coded effects or unsupported technical numbers. B) `EQUIPMENT_ASSET_ONLY` / `HYBRID_SCENE` are retained as **optional background/equipment visual prompts only**, not permitted sources for arrows or scientific words. C) Native scientific concepts selected as active references; others marked NOT_SELECTED due to scientific economy, not because every unselected proposal is proven scientifically wrong. D) Scores cannot rescue failed physics. E) Work on each candidate requires claim-level research and illustration QA before final certification.
