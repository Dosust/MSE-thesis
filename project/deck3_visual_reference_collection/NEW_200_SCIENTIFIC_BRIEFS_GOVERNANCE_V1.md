## Fail-closed methodology
1. Load canonical 14-slide text `thesis/presentations/deck3/DECK3_CHAPTER1_14SLIDES_CANONICAL_TEXT_V1.md` on feature branch and conceptual/scientific standard.
2. For each slide inspect all 20 briefs, select a minimal sufficient concept (possibly 1–2 assets), reject extras. **200 is breadth of candidate exploration, not desired slide complexity**.
3. Classify every scientific arrow as physical flow, observed port, control action, state dependence, hypothesized coupling or methodological sequence. For each, require source/destination, carried quantity where appropriate, SI units/sign, validity assumptions, justification, evidence state and falsifiability for candidate coupling.
4. Prefer images of unlabeled equipment; place accurate text, citations, arrows, equations and operating boundaries as native editable Times New Roman PPTX objects. Images cannot invent physics or numeric results.
5. No decorative boxes/fills, shadows, gradients or fine meaningless arrows. Authored design white #FFFFFF interiors, exact 13-color registered Deck3 palette, 16:9 at 13 1/3×7.5 inches. Photorealistic assets retain authentic colors.
6. No implied reverse power flow from transport-to-power influence. Ambient heat is a shared input not proof of propagation. Device derating may reduce transformer heating. Actual grid-side AC V/I/P/Q is needed before the P-side inference.
7. Ensure 24-point ordinary projection body target, cite supported claims beside them, scientific meaningful On Click native reveals, inspect render and separately actual PowerPoint playback.
8. No new image or permission-cleared source is contained in the CSV. Rank **physics validity as a hard gate**: scores cannot compensate for a scientifically false arrow or invented outcome. No source image may be copied without item-level rights.
9. Track each sample status as NOT_REVIEWED/QUALIFIED/REJECTED and each fabricated asset's originality, scientific approval, source, and usage independently. No false claims about completed validation.
10. The original 160 candidates are on research branch `research/deck3-160-visual-reference-samples-20261010`, PR #72. This new 200 is committed on Deck3 feature branch; repo merge status may differ.
