## Authority conflicts that must be controlled

Do not use the H4/H5 definitions in these files as current confirmatory authority:
- project/ENGINEERING_CONFIRMATORY_HYPOTHESIS_MATRIX.md
- project/THESIS_TRACEABILITY_REGISTER_V1.md

They retain earlier meanings:
- H4 = interface-criticality superiority;
- H5 = adaptive-pathway superiority.

Current authority is:
- H4 = intervention effectiveness/efficiency/sustainability consequence heterogeneity under RQ6/SO6;
- H5 = resilience-only versus joint resilience–sustainability engineering decision under RQ7/SO7;
- interface-criticality superiority = separate supporting diagnostic if explicitly activated;
- adaptive/sequential superiority = conditional Stage-7 extension if explicitly activated.

Use instead:
- CANONICAL_RQ_SO_HYPOTHESES_V3.md
- RQ_SO_H_TRACEABILITY_V3.md
- MODEL_EXPERIMENT_VALIDATION_MATRIX.md
- CLAIM_EVIDENCE_REGISTER.md
