## 1. Scientific identity

The thesis keeps three distinct objects:

\`\`\`math
\boxed{
\underbrace{\mathcal S_{PT}}_{\text{System-of-Systems architecture}}
\neq
\underbrace{\mathfrak G_{PT}(x,t)}_{\text{spatiotemporal structure}}
\neq

\`\`\`

The architecture/behavior separation is a thesis modeling convention, not a universal definition.

The physical core is \`P+T\`; Information and Organization are supporting knowledge/action domains.

## 3. Stage 2 — Evidence-Qualified Spatiotemporal Directional Dependencies

Candidate relations are admitted only when direction, mechanism, activation conditions, spatial/temporal support, delay, characteristic timescale, uncertainty, evidence, and validity domain are qualified.

\`\`\`math
\boxed{
\mathcal I^{cand}\rightarrow\mathcal I^{qualified}.
}
\`\`\`

Permanent firewalls:

\`\`\`math
\text{co-location}\neq\text{dependency},
\qquad
\text{association}\neq\text{causality},
\qquad
P\rightarrow T\not\Rightarrow T\rightarrow P.
\`\`\`

Causal qualification does not by itself imply numerical/dynamic readiness.

\`\`\`math

\text{physics-based hybrid multiscale dynamics}.
}
\`\`\`

## 6. Stage 5 — Uncertainty-Aware Spatiotemporal Service Resilience

The canonical conceptual core is:

\`\`\`math
\boxed{
\text{Resilience}
=
\underbrace{\text{Remain}}_{\text{viability}}
+
\underbrace{\text{Return}}_{\text{reachability}}
+
\underbrace{\text{Uncertainty qualification}}_{\Gamma_U}.
}
\`\`\`

The plus signs denote conceptual composition, not scalar addition.

### 6.1 Probability is conditional, not universal

The parent v2 wording \`confidence = probability\` is superseded by:

\`\`\`math
\boxed{
\Gamma_U=
\begin{cases}
\text{probabilistic qualification}, & \text{if a probability model is defensible},\\
\text{scenario / interval / robust / sensitivity qualification}, & \text{otherwise}.
\end{cases}
}
\`\`\`

Scenario frequency must not be interpreted as probability without independent justification.

Viability and recovery-reachability sets may therefore be probabilistic, robust, scenario-based, or bounded according to the qualified uncertainty model.

Conventional service/recovery curves remain the H3 comparator.

## 7. Stage 6 — Spatiotemporally Targeted Engineering Intervention Consequences

Resilience diagnosis informs intervention need and targeting; it does not generate normative requirements.

\`\`\`math
\boxed{
\text{diagnosis identifies relevance;}
\quad
\text{independent authority/evidence establishes requirements}.
}
\`\`\`

Each intervention is characterized, where relevant, by type, location, timing, scale/capacity, and required resources.

The canonical typed consequence object is:

\`\`\`math
\boxed{
\mathcal C(a_k)
=
\left(
\Delta\mathfrak R^{a_k},
\mathbf r^{a_k},
\mathcal E_{\rm fx}^{a_k},
\mathcal E_{\rm fy}^{a_k},
\Delta\mathbf J_{\rm sus}^{a_k},
\mathcal F^{a_k},
\mathbf U^{a_k}
\right).
}
\`\`\`

Permanent distinctions:

\`\`\`math
\boxed{
\text{resilience effect}
\neq
\text{effectiveness}
\neq
\text{resource requirement}
\neq
\text{resource efficiency}
\neq
\text{admitted sustainability consequence}.
}
\`\`\`

The core resource vector is bounded by the sustainability admission authority and currently includes direct cost and operational energy where qualified:

\`\`\`math
\mathbf r_{\rm core}\subseteq(C_{\rm direct},E_{\rm op}).
\`\`\`

The core admitted environmental sustainability consequence is:

\`\`\`math
\mathbf J_{\rm sus,core}\subseteq(CO_{2e}),
\`\`\`

with distributional accessibility/equity conditional on separate qualification.

The parent-v2 vector \([J_{\rm access},J_{\rm energy},J_{\rm carbon},J_{\rm cost}]^\top\) is therefore **not** interpreted as one undifferentiated sustainability vector.

Primary H4 is intervention-consequence heterogeneity among resilience-effective interventions; interface criticality remains a supporting diagnostic unless separately preregistered.

## 8. Stage 7 — Defensible Spatiotemporal Engineering Decision

Stage 7 asks which alternatives remain defensible after feasibility, resilience, resource efficiency, admitted sustainability consequences, and uncertainty are evaluated jointly.

The canonical ordering is:

\`\`\`math
\boxed{
\text{feasibility}
\rightarrow
\text{native-unit criteria}
\rightarrow
\text{Pareto/dominance}
\rightarrow
\text{robustness/regret}
\rightarrow
\text{preference/value model if independently justified}.
}
\`\`\`

Primary H5 compares:

\`\`\`math
\boxed{
\mathcal A_R^\star
\quad\text{vs}\quad
\mathcal A_{\rm joint}^\star.
}
\`\`\`

The joint arm uses qualified resource-efficiency and admitted sustainability-consequence information under common feasibility and uncertainty governance.

A unique optimum is not required:

\`\`\`math
\boxed{
\text{defensible}\neq\text{universally optimal}.
}
\`\`\`

Adaptive/sequential transformation is a conditional Stage-7 extension. It does not define primary H5.
