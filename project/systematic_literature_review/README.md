## One review, three classifications, four execution phases

1. **Scientific domain** C1–C6: transformer heat, EVSE/vehicle heat, physical interface, dynamical math, physics-informed learning, service resilience. One primary C class per reference, optionally multiple secondary tags.
2. **Evidence of each claim** F1–F7: connected field / partial connected field / real component field / laboratory / measured-driven model / simulation / review or standard. A paper with measured current and simulated heat can have **different F codes for different claims**.
3. **Maturity of our work** S0–S6: planned → source located → preliminary screen → extracted → source checked → independently validated (only if actual new verification) → synthesized. This is **not a score of publication quality**.

**Phases:** I WP1–3 evidence discovery, II WP4–5 scientific analysis, III WP6–7 empirical qualification and model choice, IV WP8 reporting. WP6 may proceed in parallel. The full coupled SO1–SO3 thesis remains downstream.
