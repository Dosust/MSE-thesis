## Conceptual distinction

- **Type I:** understand coupled dynamics, viability, recoverability, and feasible intervention.
- **Type II:** infer the real system from observations, update a physics-informed digital twin, predict risk, and support control decisions.
- **Type III:** evaluate design/control alternatives and derive Pareto-optimal decisions under uncertainty, sustainability, and equity constraints.

All three preserve the common end-to-end chain:

`Foundations → Representation → Dynamics → Resilience → Control → Design → Optimization → Decision`
