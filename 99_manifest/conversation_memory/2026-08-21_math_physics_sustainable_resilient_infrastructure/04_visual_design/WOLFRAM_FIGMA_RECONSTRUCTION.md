## Critical fidelity lesson

The first attempts failed because they copied a palette but used normal infographic/card logic.

The Wolfram reference instead uses **open-field computational visualization**:
- one dominant causal/multiway structure;
- spatial hypergraphs with very high edge density;
- hundreds of thin edges;
- curved trajectories and branching histories;
- sparse floating annotations;
- tiny state glyphs;
- no conventional slide/card grid dominating the composition;
- negative space used as an active scientific-design element;
- derived causal, branchial, multiway and spacetime/state-space views around a central graph.

Therefore the design rule frozen in this conversation is:

\[
\boxed{\text{Do not design boxes describing mathematics.}}
\]

Instead:

\[
\boxed{\text{Make the mathematics itself become the visual structure.}}
\]

## How to adapt the seven candidates

The visual grammar should remain fixed while the **mathematical objects change**:

1. Unified Sustainable Viability — viability boundary/state-space geometry dominates.
2. Dynamic Interface Identification — observed data, inferred interface graph, posterior uncertainty and boundary deformation become the visual objects.
3. Port-Hamiltonian Physics — energy/storage/flow ports and conserved/dissipative geometry dominate.
4. Stochastic Hybrid Physics — switching modes, stochastic trajectories and topology-changing failure graphs dominate.
5. Lifecycle OR — decision tree/branchial policy space, constraints, dual/sensitivity structures and lifecycle state transitions dominate.
6. People-Centric Service Viability — physical network to population-service graph and equity-constrained viable surface dominate.
7. Verified Scientific AI Twin — physical system ↔ sensing ↔ learned operator ↔ UQ ↔ formal safety/reachability ↔ control loop dominate.

## Future design QA

Before calling a poster “Wolfram-fidelity,” verify:
- computational graph density;
- hierarchy dominated by a central scientific object, not text boxes;
- edge/stroke fineness;
- asymmetric but balanced spatial composition;
- annotation sparsity;
- color semantics;
- legibility at full poster size;
- all mathematical objects are meaningful, not decorative;
- all important labels/lines are editable vectors;
- Figma frame compared side-by-side against the reference visual summary.
