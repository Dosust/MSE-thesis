## EGMIV — current method name

EGMIV means **Evidence-Grounded Mechanistic Interdependency and Validation Method**.

Its compact chain is

```math
\text{Evidence}
\rightarrow
\text{Mechanism}
\rightarrow
\text{Interdependency}
\rightarrow
\text{Mathematical Model}
\rightarrow
\text{Validation}.
```

The governing rule is:

> **No interdependency without direction + mechanism + mapping + type + evidence.**

When instructed to **use EGMIV deeply**, every load-bearing claim should expose evidence provenance, mechanism, mathematical mapping, competing representation, assumptions, units, parameter provenance, uncertainty, falsification test, physical admissibility, validation evidence and validity boundary.

EGMIV does not replace FTEE. FTEE is the evidence-to-equation extraction protocol inside the broader EGMIV process.

Epistemic labels remain:

- `[E]` established by external evidence;
- `[D]` derived mathematically or logically;
- `[H]` hypothesis;
- `[P]` thesis proposal;
- `[A]` assumption;
- `[U]` unresolved/uncertain.

Method selection proceeds from engineering problem → observed mechanism → scientific evidence → mathematical structure → candidate methods → assumption compatibility → benchmark → falsification/validation, not from “Paper X used method Y.”

## H1 mathematical state — 2026-09-13

The H1 physical boundary is frozen as

```math
\mathcal G_{H1}=\mathcal G_P\cup\mathcal G_T\cup\mathcal C,
```

where $P$ is a radial distribution network, $T$ is a dynamic road network and $\mathcal C$ is the charging-interface set. Information and organization are deliberately deferred to H2 to preserve causal attribution in H1.

The competing H1 representations are

```math
\boxed{
M_0=\text{independent},\qquad
M_1=\text{static/algebraic coupling},\qquad
M_2=\text{dynamic causal coupling}.
}
```

Three physical H1 interface mechanisms are currently instantiated:

1. $P\rightarrow T$: grid power limits charging service and therefore mobility service;
2. $T\rightarrow P$: EV arrivals/charging demand become electrical nodal load;
3. $T\rightarrow P$: road accessibility/travel time delays power-repair crews and resources.
