# Gemini Repository Instructions

For all active thesis work, first read:

- `AI_RESEARCH_INSTRUCTIONS.md`
- `project/CURRENT_THESIS_AUTHORITY_INDEX_V1.md`
- `project/CANONICAL_EVIDENCE_NON_INVENTION_STANDARD_V1.md`

Mandatory evidence rule:

```text
If it cannot be traced, it is not frozen.
If it cannot be verified, it remains OPEN.
If it is thesis-derived, label it T1 / thesis-derived.
If it is transferred, transferability must be justified.
```

Never invent scientific sources, DOI metadata, standards, clauses, equations, thresholds, parameters, equipment limits, material properties, validation results, uncertainty bounds, or numerical findings. Apply the current authority index before older repository material.
