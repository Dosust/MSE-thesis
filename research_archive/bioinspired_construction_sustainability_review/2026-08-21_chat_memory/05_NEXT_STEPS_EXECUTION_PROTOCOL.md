## Step 2 — PDF-level BIO58 evidence pass

Use the existing Version 1.0 schema; do not change it.

### Pass A — Assessment architecture
Extract exact passages/pages for:
- BiSA definition;
- BiSA purpose;
- environmental/economic/social function-and-burden architecture;
- environmental LCA component;
- economic costing component;
- any other directly implemented method.

### Pass B — Tool inputs
For each input, capture:
- exact author terminology;
- value and unit if reported;
- input source/origin;
- whether focal-author generated;
- whether it is genuinely an engineering-performance input;
- page/section/table/figure/equation.

### Pass C — Engineering performance
Confirm exact focal evidence for:
- residual indentation = 0.14 mm;
- permanent thickness change = 0.02 mm;
- measurement/test method;
- comparator/reference;
- any additional engineering/functional metric.

Do not infer units or methods from standards unless the paper explicitly provides them.

### Pass D — Sustainability outcomes
The priority task is to locate a **direct numeric focal sustainability output** generated by BiSA/embedded assessment.

For each result capture:
- dimension;
- indicator as written;
- exact value;
- exact unit/scale;
- alternative/reference;
- functional basis;
- method that generated it;
- page/table/figure/equation.

### Pass E — Linkage
For every candidate arrow ask:

`Does this engineering metric actually enter the sustainability assessment?`

Require a direct passage/equation/procedure.

Current fixed states until new evidence:
- intended building-physical function -> BiSA social function = L2;
- residual indentation -> BiSA = U;
- permanent thickness change -> BiSA = U.

### Pass F — Validation
Separate:
- application/demonstration;
- internal sensitivity/consistency/calibration;
- independent external validation.

Current status remains `Applied` unless focal evidence justifies more.
