> **Important:** “Accepted” means the source is admissible for the bounded claim listed below. It does **not** mean the source proves H1–H5, proves thesis novelty, or validates the complete thesis framework.

## 1. Acceptance rule

A source enters this file only when bibliographic identity is sufficiently verified, DOI/persistent link is available, publication status is known, the supported claim is explicitly bounded, direct P–T evidence is distinguished from CI-general or adjacent evidence, and arXiv/journal versions are not double-counted.

For P–T-specific claims, transferability is ordered as:

`[DIR-PT] > [DIR-CI] > [ADJ]`

This is a transferability hierarchy, not a journal-quality ranking.

## 7. Current accepted evidence boundary

The accepted set supports SoS/multilayer representation, directional infrastructure dependencies, direct P–T coupling, dynamic/spatial P–T behavior, information/organizational relevance, conventional resilience curves, viability/reachability mathematics, resilience–sustainability distinction, and robust/adaptive decision foundations.

It does **not** establish the thesis hypothesis outcomes:

- `M2 > M1`;
- `(P+T+I+O) > (P+T)`;
- `R_curve + R_vrr > R_curve`;
- `A_R* != A_RS*`.

Those remain H1–H5 tests.
