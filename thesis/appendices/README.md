# Thesis Appendices

**Title authority:** `../../project/CANONICAL_THESIS_TITLE_V1.md`

## Purpose

Preserve reproducibility, detailed evidence, technical derivations and supplementary results without obscuring the main scientific argument.

## Planned appendix families

- **Appendix A — Search protocols and database execution records**
- **Appendix B — Screening, eligibility and FTEE extraction schema**
- **Appendix C — Complete mathematical notation / derivations**
- **Appendix D — Model equations and parameter-provenance tables**
- **Appendix E — Verification, validation and uncertainty audits**
- **Appendix F — Supplementary H1–H5 results**
- **Appendix G — Reproducibility: code, software environment, seeds and hashes**
- **Appendix H — Permissions/approvals if applicable**

## ASU format note

Appendices remain subject to Graduate College margin, pagination and formatting requirements. Appendix cover-page/title conventions should be checked against the current ASU Format Manual and the chair-approved style guide at final formatting.

## Reproducibility rule

An appendix should not be used to hide a method necessary to understand or reproduce a central result; essential method information remains in Chapter 4, with detailed implementation here.
