# Thesis Completion Gates

**Status:** CURRENT / SYNCHRONIZED WITH FRAMEWORK v2, RQ–SO–H v3, CHAPTER-I v2  
**Writing/inference authority:** `SCIENTIFIC_WRITING_AND_INFERENCE_STANDARD_V1.md`

**Purpose:** define scientific completion independently of page count or visual polish.

## General section gate

For section `S_j`:

```math
\boxed{G(S_j)=C\land E\land M\land T\land R\land U\land V}
```

where:

- `C`: conceptually complete for declared scope;
- `E`: evidence complete/qualified for declared claim;
- `M`: mathematically/physically consistent where applicable;
- `T`: traceable to RQ/objective/hypothesis or developmental obligation;
- `R`: reproducible/auditable;
- `U`: uncertainty/limitations addressed where relevant;
- `V`: validity domain stated.

A section is scientifically frozen only when all required gates pass.

## Gate statuses

- `NOT STARTED`
- `ACTIVE`
- `BLOCKED`
- `PASS — WORKING`
- `PASS — FROZEN`
- `FAIL / REVISE`

## Preliminary matter gate

Pass when:
- ASU sequence correct;
- title page follows current ASU sample/template;
- abstract <=350 words and passes pronoun/acronym checks;
- lists of figures/tables match document artifacts;
- page numbering, margins, font and spacing pass current ASU requirements.

## Chapter 1 gate — Introduction

Pass when:
- Chapter-I v2 sequence and 1.1–1.13 structure are preserved;
- problem is clearly defined;
- significance is evidence-based;
- gap is qualified by Chapter-2 evidence rather than asserted;
- scope/boundary/exclusions explicit;
- exact RQ0/RQ1–RQ7 and SO1–SO7 are synchronized with v3;
- RQ1/RQ2 developmental obligations and RQ3–RQ7/H1–H5 mapping are correct;
- Stage-5 wording preserves viability + reachability + probability;
- H4 is intervention effectiveness/efficiency/sustainability consequences;
- H5 is joint resilience–sustainability engineering decision;
- interface criticality and adaptive pathways are not silently promoted to H4/H5;
- proposed contributions are not written as completed results.

## Chapter 2 gate — Literature Review & Foundations

Pass when:
- search protocol(s) executed for declared questions;
- search dates/databases/queries preserved;
- screening and exclusions auditable;
- full-text evidence qualified;
- supporting and contrary/rival evidence retained;
- assumptions/validation domains extracted;
- critical concepts have adopted definitions and operational representations;
- literature gap arises from synthesis;
- novelty claims use separate reproducible audit;
- sources/citations verified.

```math
\boxed{
\text{complete}_{Ch2}
\iff
\text{search}\land\text{screening}\land\text{extraction}\land\text{definitions}\land\text{contrary evidence}\land\text{gap support}\land\text{reference verification}
}
```

## Chapter 3 gate — Conceptual & Mathematical Framework

Pass when:
- definitions/notation registry complete;
- every symbol has type/domain/units where applicable;
- each causal arrow has mechanism and admissibility logic;
- established `[E/D]` and proposed `[P/H]` objects are separated;
- equations dimensionally/logically consistent;
- subsystem physics remain physically admissible;
- stage-to-stage handoffs defined;
- Stage-5 resilience object includes viability/reachability/probability semantics;
- Stage-6/7 intervention and decision objects match current H4/H5 logic;
- figures exactly match canonical mathematical content.

## Chapter 4 gate — Methodology & Experimental Design

Pass before confirmatory simulation when:
- rival models/baselines frozen;
- held constants and treatment/change explicitly declared;
- data provenance/qualification and calibration/validation roles frozen;
- scenario domain frozen;
- primary outcomes/metrics frozen;
- practical/engineering significance thresholds or decision rules fixed a priori;
- parameter provenance/uncertainty domains recorded;
- verification tests pass;
- validation plan frozen;
- falsification/non-support rules explicit;
- exploratory analyses labeled separately.

```math
\boxed{
\text{confirmatory authorization}
=
B\land X\land T\land D\land\Omega\land\Phi\land\delta\land V\land U\land F.
}
```

## Chapter 5 gate — Results

Pass when:
- every confirmatory result maps to a frozen Chapter-4 method;
- experiment ID and raw-to-result provenance retained;
- estimates and uncertainty reported;
- practical/decision threshold reported;
- null/negative findings retained;
- deviations/amendments disclosed;
- no exploratory output presented as confirmatory;
- causal language does not exceed design support;
- theory-to-observation discrepancies are retained rather than hidden.

## Chapter 6 gate — Discussion

Pass when:
- every interpretation traces to registered results + qualified evidence;
- rival explanations discussed;
- assumption sensitivity identifies whether conclusions change;
- validity domain stated;
- effectiveness, efficiency and sustainability remain distinct;
- sustainability implications tie to measured/modelled behavior and accounting boundaries;
- limitations and unresolved uncertainty explicit;
- generalization does not exceed validation evidence.

## Chapter 7 gate — Conclusions

Pass when:
- RQ0 and each RQ1–RQ7 answered explicitly;
- each H1–H5 status stated without overclaim;
- each answer traces to result/evidence IDs, validity domain and unresolved remainder;
- contribution categories separated: theoretical, methodological, computational, engineering, sustainability;
- proposed/unsupported claims remain proposed or future work;
- conclusions close the claim-evidence-result chain.

## Scientific writing gate

For each substantive section, apply `SCIENTIFIC_WRITING_AND_INFERENCE_STANDARD_V1.md`. A polished section fails if claims, definitions, assumptions, evidence, uncertainty, traceability or validity domain are incomplete.

## ASU final-release gate

The thesis can be labeled `DEFENSE-READY` only when:

1. committee/chair technical review completed;
2. all substantive chapters pass scientific gates;
3. references and artifact lists synchronized;
4. current ASU Format Wizard/template applied as required;
5. Graduate College format checklist passes internal audit;
6. complete document uploaded through iPOS by the current deadline requirement;
7. defense scheduling/enrollment requirements satisfied.

Page count alone never constitutes a completion criterion.
