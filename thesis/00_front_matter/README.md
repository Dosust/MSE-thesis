# Preliminary Matter — ASU-Controlled

This folder is reserved for front matter generated and audited against the current ASU Graduate College Format Manual and Format Wizard.

## Required/possible sequence

1. Title Page
2. Copyright — optional
3. Abstract
4. Dedication — optional
5. Acknowledgments
6. Table of Contents
7. List of Tables
8. List of Figures
9. Other lists — e.g., symbols/abbreviations, if used
10. Preface — optional

## Abstract gate

- maximum 350 words;
- page `i` under ASU pagination convention;
- no first-person plurals `we`, `our`, `us`;
- acronyms/abbreviations written out fully at first use;
- no bibliographic citations unless ASU guidance changes and is reverified.

## Formatting authority

Use the ASU Format Wizard and current Graduate College Format Manual for final implementation. Internal Markdown structure is planning-only and does not replace the required final ASU template.
