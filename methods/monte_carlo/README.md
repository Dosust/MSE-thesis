This directory preserves the **2026-08 literature-ranking / PRISMA-style Monte Carlo workflow** used during an earlier research-selection phase. It is retained for reproducibility and provenance.

It is **not** the current numerical implementation of the frozen P–T–I–O seven-stage framework and it does not define the current primary hypotheses $H_1$–$H_5$.

## Interpretation rule

Older files may contain historical labels such as `H1–H7`, earlier topic targets, or papers focused on infrastructure combinations that are no longer the active thesis ontology. Those labels must be interpreted **within the historical ranking protocol only**.

## Preservation rule

Do not rewrite the numerical results of a frozen historical run merely to match the current framework. Preserve the original input hashes, seeds, run counts, output statistics and historical labels. Add interpretation notes rather than changing provenance.

## Current use

These artifacts may support:

- reproducibility demonstrations;
- evidence-selection provenance;
- sensitivity-analysis method examples;
- comparison with later literature-search protocols.

They must not be cited as direct numerical validation of the current P–T–I–O dynamical framework.
